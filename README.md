# Robot Portfolio Prompt Builder

초등·중학생이 자신의 로봇·코딩 경험을 단계별로 정리하고, Google Stitch에서 개인 포트폴리오 웹앱을 만들 수 있는 프롬프트로 변환하는 화이트보드형 웹앱입니다.

## 주요 기능

- 플레이웰 디자인의 메인 화면과 4단계 제작 워크플로우 안내
- 10개의 연결된 워크플로우 카드와 이전·다음 이동
- 직접 입력, 단일 선택, 복수 선택 및 기타 항목 입력
- 선택한 포트폴리오 영역의 드래그 순서 변경과 메뉴·본문 동시 반영
- 여러 대회와 프로젝트를 반복해서 추가·삭제
- 대회명, 팀명, 자신의 역할, 잘한 점, 아쉬운 점 및 보완할 점, 한줄평 기록
- 우측 미리보기 프로젝트 카드의 상세 팝업 동작
- 입력 내용을 바탕으로 Google Stitch용 상세 프롬프트 생성 및 복사
- 브라우저 `localStorage` 자동 저장
- 데스크톱과 모바일 반응형 UI

## 개인정보와 저장 방식

학생이 입력한 내용은 서버나 GitHub로 전송하지 않습니다. 현재 사용하는 브라우저의 로컬 저장소에만 저장되며, 같은 기기와 같은 브라우저로 다시 방문하면 이어서 작성할 수 있습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기·브라우저 사용 시에는 불러올 수 없습니다.

저장소에는 웹앱 소스 코드만 포함되며 학생의 작성 내용은 포함되지 않습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```
